# Digital IC Design Benchmark for Agents

[中文](README.md)

Digital IC Design Benchmark for Agents evaluates agent systems on end-to-end digital IC RTL delivery. Its ten tasks range from combinational logic to a CPU and a multi-precision NPU. Every task assesses synthesizable RTL, an independently runnable verification deliverable, and PPA under an open flow.

See [benchmark/README.en.md](benchmark/README.en.md) for tasks, evaluation status, execution instructions, and release gates.
