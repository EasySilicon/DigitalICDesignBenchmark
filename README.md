# Digital IC Design Benchmark for Agents

Digital IC Design Benchmark for Agents 是一个面向 Agent 的数字芯片 RTL 设计与交付 benchmark。它包含从组合逻辑到 CPU 与多精度 NPU 的十道任务，并统一考察可综合 RTL、独立验证交付和开源流程下的 PPA。

完整任务、评测状态、运行方法和发布门禁见 [benchmark/README.md](benchmark/README.md)。本仓库自有代码与文档采用 [Apache-2.0](LICENSE)；再分发的第三方材料适用其各自许可证，详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
