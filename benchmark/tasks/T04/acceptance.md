# T04 · 轮询仲裁器

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-21 | 单一请求及全部请求组合，按当前指针环形选首个 valid | F 选择 |
| AC-22 | 长期全 valid 与随机撤销/加入；指针只在输出握手后推进 | F 轮询 |
| AC-23 | 每输入独立递增序号，输出 id、数据一一对应，无丢/重 | F 数据 |
| AC-24 | 输出阻塞 1–30 拍，同时其他请求变化；选中 id/data/valid 不变 | P 阻塞 |
| AC-25 | N=4/8 所有源持续请求且输出接受时，每源最多等待 N 次输出 | P 公平性 |

参考模型记录环形搜索起点与已选中且受阻的请求；只在握手时更新。变异体包含固定优先级、阻塞时重选、过早指针推进、错误 `in_ready` 多热。
