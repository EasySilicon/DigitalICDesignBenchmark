# T08 · 直接映射写回缓存

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-38 | 冷启动后读/写相同 line 的不同 word；后续命中不访问后端 | F 命中 |
| AC-39 | 冷缺失与同 index 不同 tag 的干净替换；回填地址/数据准确 | F 干净缺失 |
| AC-40 | 脏 line 被同 index 地址替换，先写回原地址完整 line，再回填新 line | F 脏替换 |
| AC-41 | 所有 WSTRB 组合、写未命中、连续部分写；先用冲突地址驱逐全部脏行，等待写回完成，再逐字节比较外部内存与参考内存 | F 部分写 |
| AC-42 | req/response 与后端 req/response 各自随机阻塞；请求和响应在阻塞期间保持 | P 握手 |
| AC-43 | 复位后所有 line 均未命中；复位前未写回的脏行数据按丢弃处理；暖命中两拍内响应且无后端请求 | P 复位/延迟 |

参考模型用 byte-addressable 内存和 16 项抽象 cache 状态独立预测 CPU 可见结果与**必须发生的后端 line 事务顺序**。变异体包含未写回脏行、错误 tag/index、写分配遗漏、WSTRB 倒序、阻塞时重复请求。
