# T10 · 持续双 1024-bit/拍输入的多精度脉动阵列矩阵乘法

评测方通过固定端口逐拍驱动连续的 16×16×64 矩阵块，采用[精确数值 oracle](public/matmul_oracle.py)逐项检查每块 16 行、共 256 个结果；候选的 UT/scoreboard 不参与判定。A/B 两条总线在无输出背压的长流中**各自连续每拍完整接收 1024 bit**，块间不可插气泡。输出四个独立行槽带块 ID，允许不同在途块的行交织；测试平台逐拍检查输入/输出吞吐、行号和块 ID。正式评分在自动验收、参考实现、缺陷变异体和 PPA 校准均冻结后启用。

合法输入模式仅为下表覆盖的 INT8/INT16、FP16/BF16、FP8、FP4、MXFP8、MXFP4；没有 FP32 或 INT32 输入模式。浮点 binary32 与整数 INT64 仅描述输出编码，验收时仍逐项检查。

无输出背压时，从每块最后一个输入拍到首行输出最多 64 拍、到末行最多 80 拍；允许计算归约与输出汇集加寄存流水，但块间输入不可出现气泡，稳态 FP4/MXFP4 仍须每拍输出 4 行。背压矩阵的行组和列使用不同结果，且含连续 FP4/MXFP4 满速块与 32 拍输出停顿重叠；错误的暂存、行选择和组间交换必须被逐项数值检查发现。

## 物理与发布证据

参考 RTL 和参赛提交均须在统一镜像与 16 vCPU、32 GiB RAM、100 GiB 可写盘限额下完成合法 Yosys 映射，不得有功能黑盒、未预期锁存器或未约束时钟/数据路径；映射网表须通过代表性十模式功能回归。固定种子 11/29/47 均须完成放置、CTS、详细布线、RC 提取，所有受约束路径在 1000 ps 下 setup/hold 非负，详细布线 DRC 违规为零。固定持续流功耗负载须经独立 oracle 检查，活动注释率至少 95%，保存每种子的面积、路径、平均功率、每块能耗、负载 hash、原始日志和资源峰值。参考实现通过功能、结构、变异体与物理证据后才能冻结 PPA 基线；这些条件不是量产签核。ASAP7 是预测性公开工艺，真实流片仍需要目标工艺的 PVT/SI、DFT、IR/EM、物理 DRC/LVS 等签核证据。跨题条件见[统一发布门禁](../../README.md#发布门禁)。
