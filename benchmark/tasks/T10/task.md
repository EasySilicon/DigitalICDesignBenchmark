# T10 · 持续双 1024-bit/拍输入的多精度脉动阵列矩阵乘法

**设计需求**：交付可综合模块 `npu_systolic_matmul_16x16`、Agent 自建数值记分牌和测试环境、PPA 探索记录。每条命令计算 `C[16][16] = A[16][64] × B[64][16]`。采用 **16×16 输出驻留（output-stationary）PE 网格**；同一命令的 A、B 使用相同 `mode`，下一条命令可不复位而切换格式。没有 bias、转置、饱和或累加到旧 C。禁止用 `real/shortreal`、DPI、黑盒或外部协处理器实现 RTL。

**固定流接口**：输入 `clk,rst_n,in_valid,in_start,in_block_id[15:0],mode[3:0],a_scale[255:0],b_scale[255:0],a_data[1023:0],b_data[1023:0],out_ready`；输出 `in_ready,out_valid[3:0],out_block_id[63:0],out_row[15:0],out_data[4095:0]`。`rst_n` 异步低有效。每次 `in_valid && in_ready` 同时传输完整的 A/B 各 1024 bit；一个块的第一拍置 `in_start=1`，其后 `w−1` 个有效输入拍置 0。第一拍锁存块 ID、模式和两组 scale；非首拍这些元数据不参与计算。首拍必须在块边界，`in_block_id` 在所有未完成块中唯一；非法 `mode=10..15` 不驱动。发送方可暂停 `in_valid`，暂停拍不计入块内拍号。DUT 一旦接受首拍，就必须为该块剩余的每一拍持续保持 `in_ready=1`，即使 `out_ready=0`；块间可以凭有限缓冲信用撤回 `in_ready`。

**持续吞吐硬门禁**：当 `out_ready=1`、发送方连续提供合法数据且无复位时，DUT 必须让 `in_ready` 连续为 1，**块与块之间不得插气泡**。因此同模式长流的块启动间隔必须恰为 `w` 拍：FP4/MXFP4 为 4 拍，INT8/FP8/MXFP8 为 8 拍，INT16/FP16/BF16 为 16 拍；混合模式流的相邻首拍间隔等于前一块的 `w`。隐藏评测使用每种模式至少 64 块连续流、FP4/MXFP4 至少 256 块连续流，以及随机混合格式长流。必须允许前一块仍在阵列计算或输出时启动下一块，不能只靠单块突发满足带宽。无限期输出背压与无限期满速输入在有限存储下不可能同时保证；背压测试允许在**块间**按信用停止接收新块，已接受块的输入拍不得停顿，所有已接受结果必须完整保留。

| ---: | --- | ---: | ---: | ---: | --- |
| 0 | INT8 | 8 | 8 | 8 | signed two's complement |
| 1 | INT16 | 16 | 4 | 16 | signed two's complement |
| 2 | FP16 | 16 | 4 | 16 | IEEE binary16 |

| 7 | MXFP8 E4M3 | 8 | 8 | 8 | OCP MX，32 元素一组，E8M0 scale |

**输入打包**：设当前被接受的数据拍号 `t=0..w−1`，A 第 `r` 行、该拍第 `j` 个元素（`k=t·L+j`）位于 `a_data[(r·L+j)·w +: w]`；B 第 `c` 列、该拍第 `j` 个元素位于 `b_data[(c·L+j)·w +: w]`，`r,c=0..15`、`j=0..L−1`。因此每拍每个操作数恰有 `16·L·w=1024` 位。MX 模式中 A 的 scale 为 `a_scale[8·(2r+floor(k/32)) +: 8]`，B 同理以列 `c` 索引；字节 `s=0..254` 表示 `2^(s−127)`，`s=255` 为 NaN，覆盖所在的 32 元素组（包括编码零）。非 MX 模式忽略 scale。没有 NVFP4 语义。

**四行/拍输出**：每拍最多 4 个独立行槽。槽 `s=0..3` 的有效位是 `out_valid[s]`，块 ID 是 `out_block_id[16s +: 16]`，行号是 `out_row[4s +: 4]`，该行的 16 个结果位于 `out_data[1024s + 64c +: 64]`。`out_ready=1` 时同拍所有有效槽原子握手；`out_ready=0` 时有效掩码及有效槽的 ID、行号和数据保持稳定。不同块的行可以同拍或跨拍交织，每块的 16 行必须恰好各输出一次，按行号递增；同拍按槽号排序。整数结果是精确 signed INT64；浮点结果低 32 bit 为 IEEE binary32，高 32 bit 为 0。没有输出背压时，每块首行必须在该块最后一个输入拍后 48 个上升沿内出现，末行在 64 个上升沿内出现。连续 FP4/MXFP4 长流进入稳态后（从首拍后第 64 拍起到最后输入拍）每拍必须有 **4 个有效输出行槽**；8-bit 模式为 2 个，16-bit 模式为 1 个。运行中复位清除所有在途块、波前、输出队列和待输出行，不得出现旧块 ID 或响应。

**数值规则**：INT8/INT16 按有符号乘法精确求和 64 项，结果不溢出 INT64。浮点元素先按格式精确解码、MX 再乘 scale，再求 64 项点积。有限输出 `D` 与无限精度点积 `S` 须满足 `|D−S| ≤ γ(128)·Σ|a_k b_k| + 129·2^(−149)`，`γ(n)=n·2^(−24)/(1−n·2^(−24))`。所有合法 MX scale 均参与验收，包括极值 scale 与混合正负输入；单项乘积或部分和在 binary32 中溢出，不改变以精确点积判定最终结果的规则，也不允许将有限最终结果输出为 NaN/∞。任一元素为 NaN、`0×∞` 或正负∞相消时输出任意 quiet NaN；精确有限值超出 binary32 有限范围或同号∞求和时输出相应符号∞。有限范围内不得输出 NaN/∞；精确零接受 ±0。E4M3 仅最高 exponent/mantissa 全一是 NaN、没有∞；E5M2/FP16/BF16 有 NaN/∞；E2M1 无 NaN/∞。不验 NaN payload 或异常标志。

**真实脉动结构与资源**：16×16 PE 各持有一个局部 C 累加状态。A 的每拍 `L` 元素向右邻 PE 寄存转发，B 向下邻 PE 寄存转发；行、列输入分别做波前错位，使 PE `(r,c)` 在每个有效波前拍处理相同 `k` 的 A/B 向量。每 PE 对当前拍的 `L` 对元素做并行乘法及局部归约，按位宽分别为 4、8、16 lane。块边界可流水重置局部累加，并用必要的结果暂存/行对齐缓存，使前后块波前重叠。允许有限输入、结果和背压缓冲；禁止全局串行计算 256 个 C、完整乘积表、片外存储或通过测试名特化。顶层须直接例化 256 个同类型 PE；每 PE 有两条各 64-bit 的寄存操作数邻接链和一条 64-bit 寄存局部结果输出。Yosys 自动检查正交 16×16 网格、注册转发、局部反馈、所有 lane 的组合依赖和 256 个结果对输出的贡献；非 PE 状态位数上限调整为 262,144，以容纳多块在途与背压缓冲。持续输入、四槽输出、块 ID、稳态行吞吐、延时、复位和数值由独立端口测试检查；结构或时序组不得人工复核。

**资源与评分**：非 PE 状态位数最多 262,144；PE 内的局部累加/结果队列也计入实际面积、时序与能耗。无额外完整乘积表、片外存储或未声明端口。16 vCPU、32 GiB RAM、100 GiB 磁盘；时限 48 小时，同模型 token 上限 200 万。F=60：INT8/INT16 10、FP16/BF16 10、FP8 两种编码 10、FP4 10、MXFP8 两种编码 10、MXFP4 10。P=15：握手、背压、块 ID 和复位 5；持续双 1024-bit/拍、四槽稳态输出、真实脉动结构与时延 5；特殊值及舍入/scale 边界 5。PPA 20、时间 5 遵循全题统一顺序和参数。物理入榜门槛为与其他九题相同的 **ASAP7/WC、1000 ps（1 GHz）** 时钟目标。持续吞吐与真实脉动结构属于 T10 正式入榜的硬门禁；任一失败时 PPA/时间分为零，其他功能分只作诊断展示。正式计分须完成独立参考、自动验收与三种子 ASAP7 PPA 基线的发布门禁。见[共享 NPU 验收计划](../../npu-validation.md)。
