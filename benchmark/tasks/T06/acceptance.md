# T06 · 异步 FIFO

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-26 | 写入携带唯一序号，读出严格递增且恰一次，结束时队列清空 | F 顺序 |
| AC-27 | 长期快写/慢读及反向；任何已接受写不能覆盖未读数据，不能空读；满写后 `rd_ready=0` 连续 200 个读时钟时须最终声明数据有效且保持稳定 | F 空满安全 |
| AC-28 | 周期比 2:3、3:5、接近 1:1，含相位偏移和缓慢周期变化 | F 时钟比例 |
| AC-29 | WIDTH=8/32、DEPTH=8/16 组合 | F 参数 |
| AC-30 | 两域复位同时拉低、分别释放；运行中重新复位后无旧项 | P 复位 |
| AC-31 | 四种参数配置的目的域双级同步和本地复位自动网表检查；Gray 编码等其余需求以固定端口长流、动态时钟比和缺陷变异体检验可观察后果，不宣称完整 CDC 签核 | P CDC 结构 |

参考模型的队列只由写域成功握手追加、读域成功握手弹出；不要求 `wr_ready/rd_valid` 在某个固定跨域延迟出现，但要求安全与最终可见。静态检查基于 elaborated 连接关系，候选自带 `ASYNC_REG`/`cdc_sync` 注释仅作为定位提示，**不得自动豁免**缺级、旁路或组合跨域违规。静态检查不将“模拟未出现亚稳态”当作 CDC 合格证明。变异体包含缺一级同步、二进制指针直接跨域、满判少最高位、复位单域残留。
