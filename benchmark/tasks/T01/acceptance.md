# T01 · 优先编码器

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-01 | 8 个单热输入；输出恰为置位 bit 编号 | F 单热 |
| AC-02 | 所有 247 个多热输入；`out = floor(log2(in))` | F 多热 |
| AC-03 | `in=0` 时 `out=0` | P 零输入 |
| AC-04 | 在同一仿真中按固定洗牌顺序遍历 256 值；输入回到旧值时输出相同，无状态滞后 | P 组合响应 |

独立 oracle 是 8-bit 整数最高置位计算；对全部 256 值穷举。变异体至少包括优先方向颠倒、输出 one-hot、零输入错误、位 7 漏判。
