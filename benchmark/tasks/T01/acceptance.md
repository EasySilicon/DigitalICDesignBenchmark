# T01 · 串入并出寄存器

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-01 | 按 MSB 到 LSB 输入 `0x00`、`0xFF`、`0xA5`、`0x5A` 等完整字；第 8 沿后输出原字 | F 首字 |
| AC-02 | 不清空 DUT 连续输入至少 256 bit；每沿后输出最近 8 bit 的窗口 | F 连续流 |
| AC-03 | 每个下降沿改变 `serial_in`，下降沿后输出不变；下一上升沿才采样 | P 上升沿 |
| AC-04 | 两个时钟沿之间多次改变输入，`parallel_out` 保持 | P 沿间稳定 |

前 7 沿不判断上电未知位。参考模型维护软件 8-bit 左移寄存器；第 8 沿后才启用完整比较。变异体至少包括反向移位、下降沿采样、每八位错误清空、输出组合跟随输入。
