# 十题的设计领域与难度覆盖论证

本页说明[任务卡](tasks.md)为何能检验不同的数字 IC 设计能力。它是**需求覆盖论证**：每项能力都对应题面和独立验收组；并不声称十题覆盖全部芯片研发，也不把设计时的难度序号当成实测结果。实际难度间距须按[校准流程](methodology.md#难度校准)验证。

## 覆盖范围的可核查结论

- **八类主要领域**均有专门题目：基础组合逻辑、单时钟状态控制、流式缓冲与仲裁、片上总线与外设、CDC、存储层次、处理器、NPU/DSP 矩阵算术。T10 补上乘法阵列和低精度浮点/块缩放。
- **时钟与状态尺度**从无状态组合逻辑，到单寄存器、单时钟多状态、双异步时钟、五级流水线和 2D 波前阵列；检验的不是同一种 RTL 模板的十个变体。
- **接口与协议**包含纯组合、ready/valid、APB4、AXI4-Lite、line 后端和 CPU 指令/数据接口；至少三题专门施加背压、乱序到达的独立通道或外部等待。
- **横向能力**包括参数化（T03/T05/T06）、复位及事件优先级（T03–T10）、独立模型验证（全部题）、统一 ASAP7 布线后 PPA 评估（已校准题）。T10 的物理基线尚待补全。
- **难度结构**预置 1–3、4–6、7–9 三档及第十题压力项；逐题时限为 30 分钟至 48 小时。T10 是否确实难于 T09，以及新增后整体难度间距，必须用参考工程师和多种 agent 的预算内通过率、对数完成时间检验。

## 结论边界与后续扩展

十题**未覆盖** NoC、DDR/高速 I/O、DFT/扫描、低功耗多电源域、安全 IP、模拟/混合信号和真实流片签核。现阶段的结论应写成“覆盖多类常见可综合数字 RTL 设计课题”。十题已达到题量上限；如果试运行显示某一领域不能区分系统能力，需替换题目。公开 CVDP 两题必须单列，避免其潜在训练数据暴露影响原创题的解释。
