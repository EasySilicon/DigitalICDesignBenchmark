# T01–T08 独立验收器设计

本文件将[任务卡](tasks.md)的 F/P 子项落实为测试组。表中的场景是**应覆盖的行为类**，不能仅凭表格视为已通过发布门禁。九题已有私有独立验收器，参考 RTL 均通过当前功能评分；T06 的 AC-31 使用四种参数配置的自动双级链检查，加评测方持有、按源文件哈希绑定的 CDC 结构审查。T09 已接入 45 条 ACT4、108 条定向 ELF、100 条固定种子长程序、独立 Sail 提交 oracle、80 组总线等待、4 组运行中复位、64 项延时检查和流水线结构审查。PPA 参数、负载及交付门禁尚未冻结，因此目前不生成正式榜单。公开包提供[端口冒烟](../evaluator/README.md)；隐藏程序和种子保存在封闭评测器。每组测试必须有独立 oracle、超时上限和失败时的最小复现日志。CPU 测试另见[cpu-validation.md](cpu-validation.md)。

## 通用规则

- 每个 `AC-xx` 组映射到任务卡列出的一个或多个 F/P 子项，评分脚本保留组与子项的双向映射。场景重复不能重复得分。
- 时序题的驱动在非采样沿改变，沿后经过一个仿真 delta 再比较；组合题改变输入后等待组合稳定。两个时钟域分别按各自时钟的采样规则运行。
- 公共测试提供至少一个 PASS 轨迹与一个故意失败轨迹的预期日志；隐藏测试失败必须输出任务 ID、组 ID、种子、首次失败周期/事务、输入与期望/实际。
- 所有随机流由固定种子生成，生成器校验自己输出满足协议假设。参考模型只根据已接受事务更新，不窥探 DUT 内部状态。
- 对被测 RTL 的超时取该组参考实现最坏周期的至少 5 倍；含外部可变延迟的组使用任务卡上限建模。超时阈值在正式版锁定，不依据参赛者表现改变。

## T01 · 优先编码器

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-01 | 8 个单热输入；输出恰为置位 bit 编号 | F 单热 |
| AC-02 | 所有 247 个多热输入；`out = floor(log2(in))` | F 多热 |
| AC-03 | `in=0` 时 `out=0` | P 零输入 |
| AC-04 | 在同一仿真中按固定洗牌顺序遍历 256 值；输入回到旧值时输出相同，无状态滞后 | P 组合响应 |

独立 oracle 是 8-bit 整数最高置位计算；对全部 256 值穷举。变异体至少包括优先方向颠倒、输出 one-hot、零输入错误、位 7 漏判。

## T02 · 串入并出寄存器

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-05 | 按 MSB 到 LSB 输入 0x00、0xFF、0xA5、0x5A 等完整字；第 8 沿后输出原字 | F 首字 |
| AC-06 | 不清空 DUT 连续输入至少 256 bit；每沿后输出最近 8 bit 的窗口 | F 连续流 |
| AC-07 | 每个下降沿改变 `serial_in`，下降沿后输出不变；下一上升沿才采样 | P 上升沿 |
| AC-08 | 两个时钟沿之间多次改变输入，`parallel_out` 保持 | P 沿间稳定 |

前 7 沿不判断上电未知位。参考模型维护软件 8-bit 左移寄存器；第 8 沿后才启用完整比较。变异体包含反向移位、下降沿采样、每八位错误清空、输出组合跟随输入。

## T03 · 同步 FIFO

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-09 | 只写、只读、交替与随机 10 万次已接受事务；输出与软件队列头一致 | F 顺序 |
| AC-10 | 填到 `DEPTH`，下一笔无弹出时不能接受；读空时不能产出 | F 空满/容量 |
| AC-11 | 满状态同沿 `in_valid=out_ready=1`，旧头被取、新尾被存，数量不变 | F 同时操作 |
| AC-12 | WIDTH=8/32，DEPTH=3/8/16 均通过同一事务组 | F 参数 |
| AC-13 | 非空、满、随机占用中拉低复位；复位后无旧数据 | P 复位 |
| AC-14 | `out_valid && !out_ready` 连续随机 1–30 拍，数据/valid 不变 | P 阻塞 |
| AC-15 | DEPTH=3 写读多次绕回，逻辑顺序与容量不变 | P 非 2 次幂 |

参考模型为 Python `deque`，同时握手时先核对/弹出旧头，再追加新尾。空时同周期输入不准被输出。变异体包含满时拒绝替换、计数一位不足、环绕到 2 的幂、输出阻塞时覆盖。

## T04 · APB4 定时器

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-16 | 四个偏移读写、保留位、PSTRB 组合、PPROT 各值以及 STATUS W1C | F 寄存器 |
| AC-17 | COUNT 从 3 到 0、LOAD 为 0/1/任意值、auto reload 开/关；对照逐拍模型 | F 计数 |
| AC-18 | pending 设置、保持、清除，irq_en 切换时 irq 组合响应 | F 中断 |
| AC-19 | setup 保持多拍不产生副作用；access 才提交；连续两笔 APB 不丢写 | P 总线时序 |
| AC-20 | 复位、未对齐/未知偏移、终点与 COUNT/STATUS 同沿写入的优先级 | P 边界 |

软件模型先根据沿前值计算 timer 变化，再按非零 `PSTRB` 的写入字节和 STATUS W1C 覆盖同名字段；零 `PSTRB` 写入不得阻止该沿的计数事件。变异体包含 setup 提前写、STATUS 写 0 清除、PSTRB 忽略、终点迟一拍、无效地址误答成功。

## T05 · 轮询仲裁器

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-21 | 单一请求及全部请求组合，按当前指针环形选首个 valid | F 选择 |
| AC-22 | 长期全 valid 与随机撤销/加入；指针只在输出握手后推进 | F 轮询 |
| AC-23 | 每输入独立递增序号，输出 id、数据一一对应，无丢/重 | F 数据 |
| AC-24 | 输出阻塞 1–30 拍，同时其他请求变化；选中 id/data/valid 不变 | P 阻塞 |
| AC-25 | N=4/8 所有源持续请求且输出接受时，每源最多等待 N 次输出 | P 公平性 |

参考模型记录环形搜索起点与已选中且受阻的请求；只在握手时更新。变异体包含固定优先级、阻塞时重选、过早指针推进、错误 `in_ready` 多热。

## T06 · 异步 FIFO

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-26 | 写入携带唯一序号，读出严格递增且恰一次，结束时队列清空 | F 顺序 |
| AC-27 | 长期快写/慢读及反向；任何已接受写不能覆盖未读数据，不能空读；满写后 `rd_ready=0` 连续 200 个读时钟时须最终声明数据有效且保持稳定 | F 空满安全 |
| AC-28 | 周期比 2:3、3:5、接近 1:1，含相位偏移和缓慢周期变化 | F 时钟比例 |
| AC-29 | WIDTH=8/32、DEPTH=8/16 组合 | F 参数 |
| AC-30 | 两域复位同时拉低、分别释放；运行中重新复位后无旧项 | P 复位 |
| AC-31 | 四种参数配置的目的域双级同步和本地复位自动检查；评测方审查 Gray 编码每次成功传输只变一位、二进制指针不跨域直用、存储与控制边界；[公开双级链检查](../evaluator/README.md#t06-双级同步结构检查原型)只覆盖自动部分 | P CDC 结构 |

参考模型的队列只由写域成功握手追加、读域成功握手弹出；不要求 `wr_ready/rd_valid` 在某个固定跨域延迟出现，但要求安全与最终可见。静态检查基于 elaborated 连接关系，候选自带 `ASYNC_REG`/`cdc_sync` 注释仅作为定位提示，**不得自动豁免**缺级、旁路或组合跨域违规。静态检查不将“模拟未出现亚稳态”当作 CDC 合格证明。变异体包含缺一级同步、二进制指针直接跨域、满判少最高位、复位单域残留。

## T07 · AXI4-Lite/APB4 桥

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-32 | 全 strobe/部分 strobe/零 strobe 写；APB 侧记录地址、数据、PSTRB、PPROT | F 写 |
| AC-33 | 读合法 aperture，APB 返回不同数据；AXI RDATA、PPROT、响应恰一次 | F 读 |
| AC-34 | 合法成功、PSLVERR、未对齐、越界分别映射 OKAY/SLVERR/DECERR；错误时无错误 APB 副作用 | F 响应 |
| AC-35 | AW 先 W、W 先 AW、同拍到达，夹杂 AR；服务顺序遵循轮询且不饥饿 | P 通道并发 |
| AC-36 | APB PREADY 延迟 0–15 拍，BREADY/RREADY 任意阻塞；所有等待期间载荷保持 | P 背压 |
| AC-37 | 在 AW 单独缓存、APB SETUP/ACCESS、响应阻塞中分别复位；释放后无幽灵事务 | P 复位 |

APB 从设备模型按 `PSEL && PENABLE && PREADY` 接受一笔，记录完整事务；AXI 主模型独立驱动五个通道。变异体包含假定 AW/W 同拍、SETUP 即提交、PSTRB 错映、响应被背压覆盖、PSLVERR 丢失。

## T08 · 直接映射写回缓存

| 组 ID | 刺激与期望 | 关联分项 |
| --- | --- | --- |
| AC-38 | 冷启动后读/写相同 line 的不同 word；后续命中不访问后端 | F 命中 |
| AC-39 | 冷缺失与同 index 不同 tag 的干净替换；回填地址/数据准确 | F 干净缺失 |
| AC-40 | 脏 line 被同 index 地址替换，先写回原地址完整 line，再回填新 line | F 脏替换 |
| AC-41 | 所有 WSTRB 组合、写未命中、连续部分写；先用冲突地址驱逐全部脏行，等待写回完成，再逐字节比较外部内存与参考内存 | F 部分写 |
| AC-42 | req/response 与后端 req/response 各自随机阻塞；请求和响应在阻塞期间保持 | P 握手 |
| AC-43 | 复位后所有 line 均未命中；复位前未写回的脏行数据按丢弃处理；暖命中两拍内响应且无后端请求 | P 复位/延迟 |

参考模型用 byte-addressable 内存和 16 项抽象 cache 状态独立预测 CPU 可见结果与**必须发生的后端 line 事务顺序**。变异体包含未写回脏行、错误 tag/index、写分配遗漏、WSTRB 倒序、阻塞时重复请求。
