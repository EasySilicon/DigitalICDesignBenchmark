# T01–T10 独立验收器设计：共享规则与索引

本文件将各[任务卡](tasks.md)的 F/P 子项落实为测试组。表中的场景是**应覆盖的行为类**，不能仅凭表格视为已通过发布门禁。T01–T09 已完成任务级 1 GHz PPA 基线校准，T10、工具镜像和整套发布门禁仍待完成，因此目前不生成正式榜单。[端口冒烟与独立验收器](../evaluator/README.md)的源码随仓库公开；正式试做时，只把任务材料和公开冒烟复制进被测 Agent 的工作区，验收程序与种子不进入该工作区。每组测试必须有独立 oracle、超时上限和失败时的最小复现日志。

任务专属的测试组、参考模型和缺陷类别位于各任务目录中的 `acceptance.md`；本文件只保留跨题共享规则和任务索引。

## 通用规则

- 每个 `AC-xx` 组映射到任务卡列出的一个或多个 F/P 子项，评分脚本保留组与子项的双向映射。场景重复不能重复得分。
- 时序题的驱动在非采样沿改变，沿后经过一个仿真 delta 再比较；组合题改变输入后等待组合稳定。两个时钟域分别按各自时钟的采样规则运行。
- 公开冒烟提供至少一个 PASS 轨迹与一个故意失败轨迹的预期日志；独立验收失败必须输出任务 ID、组 ID、种子、首次失败周期/事务、输入与期望/实际。
- 所有随机流由固定种子生成，生成器校验自己输出满足协议假设。参考模型只根据已接受事务更新，不窥探 DUT 内部状态。
- 对被测 RTL 的超时取该组参考实现最坏周期的至少 5 倍；含外部可变延迟的组使用任务卡上限建模。超时阈值在正式版锁定，不依据参赛者表现改变。
