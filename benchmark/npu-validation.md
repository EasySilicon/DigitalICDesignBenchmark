# T10：持续双 1024-bit/拍脉动阵列验收计划

本计划细化[题卡](tasks.md)和[验收组](acceptance.md)。**新版流接口是当前规范**；旧单块命令接口、20 块公开冒烟和 960 块私有试跑只保留为历史诊断，不得给新版正式分数。精确格式和数值规则仍以[公开 oracle](tasks/T10/public/matmul_oracle.py)及题卡为准。新版公开持续流冒烟、私有混合流、同模式长流、背压和复位驱动已有可执行原型；评测方独立参考 RTL 已通过 2,624 块完整流式回归、复位探针和自动结构检查。14 个可编译缺陷变异体已全部检出，物理实现和 PPA 基线仍待完成，T10 保持 `design_only`。

## 带宽与端口模型

每个输入握手传输 A/B 各 1024 bit。块首拍 `in_start=1`，同拍采样 16-bit 块 ID、mode 和两个 256-bit scale；其余 `w−1` 个有效拍依次传送 k 方向数据，`in_start=0`。一旦首拍被接受，DUT 必须为该块余下的每个时钟保持 `in_ready=1`；发送方暂停 `in_valid` 时计数不变。无输出背压的长流中，首拍间隔严格为前一块的 `w`，块间无气泡。随机混合流按前一块模式计算下一首拍时间。

旧的单行 1024-bit 输出端口无法匹配 FP4 每 4 拍一块的输入率：一块有 16 行，输出至少要 16 拍。新版输出最多每拍 4 个独立的 1024-bit 行槽，各带块 ID 和行号，槽号递增定义同拍顺序。`out_ready` 一次接收当拍所有有效槽；背压时有效槽元数据和数据保持不变。每块输出 0..15 行恰好各一次、按行号递增；不同块可以交织。无背压时每块首行在最后输入拍后 ≤48 拍、末行 ≤64 拍。运行中复位丢弃所有在途块，复位释放后不得出现旧 ID。

**有限缓冲与背压**：无限输出停顿下不要求无限输入吞吐。DUT 可在块边界撤回 `in_ready`，但已接受块的余下输入拍不得被阻塞，输出不得丢失或重复。测试包含最长 32 拍的连续输出背压，以及满速长流中撤回、释放 `out_ready` 的恢复过程；在 `out_ready=1` 且无积压的正式吞吐窗口内不得以背压例外放宽速率。

## 必跑的自动验收组

| 组 | 隐藏刺激与检查 |
| --- | --- |
| MM-INT | INT8/INT16 各至少 64 块；零、单点、高位、±1、最大/最小值、交替符号和随机满密度；256 个 signed INT64 精确相等 |
| MM-F16 | FP16/BF16 各至少 64 块；±0、最小/最大次正规、最小 normal、相邻指数、抵消和随机矩阵 |
| MM-F8 | E4M3/E5M2 各至少 64 块；最高值、最小次正规、正负号和特殊值编码 |
| MM-F4 | 至少 64 块；全部 16 种 nibble，k=0/31/32/63 与最高输入位参与结果 |
| MM-MX8 | E4M3/E5M2 各至少 64 块；scale 0/126/127/128/254/255、独立行列配置、跨 k=31/32；定向检查超出 binary32 的正负项抵消后最终为 1，以及有限/无穷边界 |
| MM-MX4 | 至少 96 块；两个 scale block、最高 nibble、极值抵消与有限/无穷边界 |
| MM-PROTO | 首拍与块 ID、输入暂停、输出背压、元数据仅首拍有效、相邻格式切换、运行中复位；每块全部 256 个数值结果仍须正确 |
| MM-SYSTOLIC | 16×16 PE 自动网表检查；如下持续吞吐、四槽输出、块内不停顿、逐块延时和混合流；每块全部 256 个数值结果仍须正确 |
| MM-CORNER | NaN、真∞、0×∞、正负∞相消、MX scale=255、真负∞与溢出的正有限部分和、舍入边界和高 32 位零 |

| 持续流 | 无背压输入/输出窗口 | 必须自动检查的稳态输出 |
| --- | --- | --- |
| ST-4 | FP4 与 MXFP4 各至少 256 块，各块首拍严格相隔 4 拍 | 首块首拍后第 64 拍至最后输入拍，每拍 `popcount(out_valid)=4`，且 `in_ready=1` |
| ST-8 | INT8、两种 FP8、两种 MXFP8 各至少 64 块，各块首拍相隔 8 拍 | 对应窗口每拍 `popcount(out_valid)=2`，且 `in_ready=1` |
| ST-16 | INT16、FP16、BF16 各至少 64 块，各块首拍相隔 16 拍 | 对应窗口每拍 `popcount(out_valid)=1`，且 `in_ready=1` |
| ST-MIX | 至少 512 块固定种子混合模式，包含 4→16、16→4、MX scale 切换 | 相邻首拍间隔等于前块 `w`；所有行按 ID 归属且无丢失、重复、串块 |
| ST-BP/RST | 128 块 INT8/MXFP4 混合流中周期性连续 32 拍输出背压；部分块内由发送方插入一拍 `in_valid=0`，非首拍故意改变 ID、mode、scale；另在块内、波前及待输出时分别复位 | 背压期间有效槽稳定；块间可等信用、块内 `in_ready` 始终为 1；仅首拍元数据生效；已接受块完整结束或被复位整体丢弃；恢复后不死锁 |

稳态窗口从首拍被采样的上升沿计起，第 64 个后续上升沿开始，持续至最后输入拍的上升沿。禁止把先缓存整块、等全部输出后才接受下一块的设计计为持续吞吐通过。每个失败记录组、种子、块 ID、模式、输入拍/输出周期、行列坐标、预期/实际值与端口握手；每块比较全部 256 个结果，数值错误使该块不通过。

## 结构、物理与发布

Yosys 网表自动检查 256 个同型 PE、两组正交 16×16 寄存邻接链、局部累加反馈、所有 lane 对结果的影响、所有 PE 结果对输出的贡献，以及非 PE 状态位数 ≤262,144。结构规则不读取信号名或人工评审意见。性能以端口周期判定；网表正确而不能持续收/发的设计不得 MM-SYSTOLIC 分。参考和变异体必须对新接口重建，至少 12 个有效缺陷变异体含“单块突发通过但块间插气泡”“四槽输出不足”“块 ID 串扰”“满队列后丢行”。

正式 PPA 目标使用 T01–T09 相同的 Yosys/ASAP7/OpenROAD、**1000 ps / 1 GHz** WC 和种子 11/29/47；十题参考基线都须重新完成。功耗负载必须覆盖持续流的稳态。功能、吞吐、交付和物理条件均通过后才建立独立参考三元组；逐提交评分全自动。当前私有流式样例共 2,624 块（960 块数值矩阵连续输入、1,024 块同模式长流、512 块固定种子随机混合长流、128 块背压流），另有独立复位探针。评测方独立参考 RTL 的 2,624 块全部通过、13 个阶段的输入气泡/稳态行速率错误位均为零，复位探针和 256 PE 结构检查通过；14 个可编译缺陷变异体已全部检出，1 GHz PPA 尚未校准，T10 仍为 `design_only`。更多边界见[工程质量门禁](npu-quality-gates.md)。
